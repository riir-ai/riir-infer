## Model facts (from the paper + HF model card)

- nGPT backbone, 4B: 72 layers = 16-layer input block + **40-layer SHARED recurrent block** + 16-layer output block; 3:1 SWA/full attention interleave (W=1024, θ_S=1e4 / θ_F=1e7), gated GQA 16Q/4KV.
- Loop recurrence: `s_0 = x; u_t = N(s_{t-1} + x); s_t = N(F_θ(u_t))` — input-block output re-injected EVERY loop; L2 norm (FP32, ε=1e-6) at both boundaries; learned per-channel residual-rate scales (`a = |α̂|`, init 0.0177), σ₀=0.0177 logit scales; NO learned recurrence adapter. Effective depth 32+40k.
- Checkpoints: `nvidia/NVIDIA-Nemotron-Labs-Dory1.0-4B-GGUF` (Q5_K_M ~3.7 GB), BF16, MXFP8, NVFP4 — OpenMDW-1.1.
- Serving facts (paper-reported): k=1→4 avg 35.2→40.6 over 12 benchmarks; k=4 → 1.3–2.5× fewer output tokens (agentic); k=2 best gain/compute; last-loop KV −2.12..+0.42 pts @ k=4; self-spec (k=1 draft γ=4 / k=4 verify) 1.37–1.71× throughput. (The community-reported k=4 GGUF default lives in Risks — verify at T0, not here.)
