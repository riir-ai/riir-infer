## Background

Deletion Tuning deploys a trained BINARY mask over a frozen model's gate projections — zero new weight values, <0.05% of weights deleted, 1 bit/weight, 0.5–30 MB bit-packed+zstd vs GB-scale FFT checkpoints. The deployment is GD-free (frozen weights + deterministic mask), which makes the entire serving half a substrate question for THIS repo: a mask artifact format, its application to dense GGUF weights and to packed ternary PQ2_0 codes, per-task hot-swap, and audit tooling. The authors released trained masks (e.g. `grpo/qwen2.5-7b-simplerl-zoo`), so every cell below is runnable TODAY with zero training.

**Ternary-native angle (the differentiator):** deletion (→0) is in-distribution for PQ2_0 — code 1 IS the zero symbol; codes are {0→−1, 1→0, 2→+1, 3→+2} and the spare code-3 state is measured UNUSED (0.000% across 30.72M real Bonsai-27B weights, `src/quant/q2_0.rs` module doc). A masked PQ2_0 model stays a valid PQ2_0 model; the kernel bit-path is unchanged by construction. The trained-mask content producer is riir-train Plan 494; closed-form content solvers are T7 here.

## Tasks

Header: version, **base-model BLAKE3 binding** (refuse a wrong base BEFORE any weight math), section map (tensor name → bit range), zero-code constant. Precedents: `reflexer-vessel` format, `lora.bin` blake3 discipline, artb compiled-once law.
- [ ] **T2 — dense application.** Apply-at-load into the shared weight copy (the `gguf_loader.rs` seam; preferred posture) + an in-forward dequant-zeroing variant. - [ ] **T3 — ternary PQ2_0 application (the crown jewel).** Mask bit=0 → rewrite the 2-bit code to `01` (native zero). Bulk form: byte-pair LUT over (codes byte, mask byte) = **2¹⁶ entries — an exhaustive proof domain, complete, not sampled**; SIMD-friendly, branch-free, zero-alloc. Group metadata: ternary kernels precompute per-block sums/scales from codes — RECOMPUTE block metadata at materialization (one pass) and pin a stale-metadata tripwire (mutate one code → the metadata digest must move). Skip-path parity: a sparsity-optimized kernel must treat a masked zero identically to a native zero — bit-exact. **Falsifiers:** masked-zero vs native-zero digest divergence on any skip path; metadata reuse across masks. Verify-first: read the packing code for whether the spare code-3 state enables identity regions with no rewrite (the LUT works either way).
