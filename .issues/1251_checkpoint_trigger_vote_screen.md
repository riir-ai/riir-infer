# Issue 1251: Trigger-vote screen for finetuned checkpoints (supply-chain backdoor audit)
**Status:** Open — unclaimed (katgpt-rs research 693, 2026-11-25; lane: checkpoint ingest audit)

Anthropic Fellows pair (Part 2, alignment.anthropic.com/2026/neuron-basis-applications/, Appendix C.4): "neuron voting" ranks backdoor trigger tokens from weights alone — each neuron votes for the 15 tokens whose gate/up pre-activations changed most vs the base checkpoint; tokens are ranked by votes; on 74 backdoored models this puts 54% of trigger words in the top-50 with no prompting, beating summed-change (55/74) and embedding-shift (63/74). Published sibling that must be cited, never claimed novel: arXiv:2611.19304 "A Backdoor Trigger Is Legible in Fine-Tune Weights" (2026-11-14, down-proj readout mechanism + adaptive-attack evasion arm) and PEFTGuard (IEEE S&P 2025, adapter-weight detection). The CLASS is published. Ours differs by: machinery (the synthetic-backdoor fixture rides our OWN `closed_form_write` / `weight_edit_overlay` lanes — 980/1189 — so the detector and the planter share one substrate and one falsifier) and target (a supply-chain screen for checkpoints WE ingest — the riir-train `data/BASE_MODELS.md` pins and any third-party GGUF — the detective half of the 268/422 provenance story; 422's constructive-cryptographic half is untouched).

Companion finding from the same pair that shapes the audit posture: 14/23 WMDP-cyber unlearning checkpoints still rank correct answers first under cloze scoring, and the methods that pass the standard metric mostly implement a backdoor (topic text = trigger, noise = behavior) — so a trigger screen is also the natural first probe when auditing any behavior-modified checkpoint we did not train.

- [ ] T1 — vote implementation over a (base, finetune) GGUF pair: per-token Δ(w_gate·e) and Δ(w_up·e); per-neuron top-15 votes; layer-band admission rule (paper C.4: extend layers while the top-100 vote lists share ≥10 tokens with the previous layer); deterministic ranking (Issue-940 fold + first-index tie rule); artifact in the census lane shape.
- [ ] T2 — fixture battery, TWO planters, each on a COPY of the local `riir-train/data/Qwen3.5-0.8B-Base-Q8_0.gguf` with the base preserved for diffing:
  - **T2a (sanity check, circular by construction):** trigger-token gate/up delta via `closed_form_write`. The vote ranks by Δ(w_gate·e)/Δ(w_up·e), so this planter writes exactly the statistic the detector reads — recovery is near-guaranteed. Reported for harness sanity only, NEVER the deciding cell.
  - **T2b (the actual cell, non-circular):** a down-proj-only write whose trigger condition comes from an upstream feature (a residual direction or attention-read gate — NOT the gate/up rows the vote reads), so the vote's statistic is only indirectly perturbed; and/or a short LoRA trained on poisoned trigger pairs on a GPU lane (amo/4090 per the compute law — never m3), the result an observation fixture, never a shipped primitive. If only the circular planter passes, the cell closes UNPROVEN, never PASS.
- [ ] T3 — recovery cell, bars PINNED at filing: over ≥3 planted triggers (distinct trigger tokens) in the T2b fixture(s), the vote must rank ≥⅔ of planted triggers in its top-10 AND at ≥2× the better-ranked of the two baselines (summed-change, embedding-shift). Only-T2a passing → close UNPROVEN. Both failing → close NEGATIVE, the screen dies pre-flight. The fixture is OURS (grammar-not-answers: no published test rows are ingested anywhere in this lane); the paper's 54%@top-50 is a real-organism reference figure, never our bar.
- [ ] T4 — real-organism arm: Claude-verdict scope (recorded here; runs automatically if T3 passes — a public-checkpoint download + scoring is neither a credential nor a secret touch, so no owner gate under the Gating law): ONE public backdoored organism from the pair's 74-model corpus (the Thoughtworks HF release of backdoored Llama-3.1-8B/Llama-3.2-3B/Gemma-2/Qwen2.5 organisms with documented triggers; cite the exact dataset handle at run time) as the external check; the run downloads the public checkpoint from Hugging Face when absent (public read, no credential) and skips loud only if the download or load fails.
