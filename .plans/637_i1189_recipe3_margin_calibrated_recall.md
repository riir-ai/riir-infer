## The one-line recipe-3 hypothesis

**At the first position where the base greedy continuation diverges from the answer (the battle position), replace the absolute target direction `unit(E[answer_k] ⊙ g)` with the differential `unit((E[answer_k] − E[competitor_k]) ⊙ g)` — where `competitor_k` is the CURRENT model's greedy token at that position, re-captured every refinement round (base-state capture = round 0) — sized by the margin the write must close and normalized by the differential direction's own logit gain: `movement = D_margin / |(E[answer_k] − E[competitor_k]) ⊙ g|`. Later positions keep absolute targets: the write gains the ability to push AGAINST the incumbent answer, which is the only move a mis-ranked fact's recall actually requires.**

Mechanics, all inside the existing closed-form pipeline (zero new math beyond one vector subtraction, one logprob difference, and one norm):

- **Battle position (the general rule, verdict amendment 5):** the FIRST position k where the base greedy continuation differs from the answer — exactly the position `gen_fit`'s depth counter stops at. On the anchor the divergence is at position 0 (Gitega vs Bujumbura), so the cell is unaffected; the rule generalizes correctly when the competitor shares the answer's first subword (where a literal-position-0 reading would silently fall back everywhere and never engage).
- **Competitor capture (verdict amendments 4 + base-state pin):** round 0's competitor comes from a base-state capture at the top of `construct()` (pre-overlay, pristine base for every fact — same precedent and determinism class as `ProtectSpec.control_asks`' model-answered continuations; greedy, first-index tie rule, no RNG). **Every refinement round 1..n re-captures the CURRENT model's greedy token at the battle position** — the margin is read at the current overlay state, so a frozen base competitor would aim at an opponent that has left the race (after the write pushes the answer past it, the margin would clamp to 0 and the target would shrink to the floor while a NEW argmax holds the battle). The per-round competitor id is recorded in the manifest (per fact, per round) for post-hoc audit.
- **Movement normalizer (verdict amendment 1 — the math flaw that would have sunk the cell):** the absolute path's divisor `|E[t] ⊙ g|` is the logit gain per unit of residual movement along `unit(E[t] ⊙ g)`. Along the differential direction the gain per unit of movement is `|(E[answer_k] − E[competitor_k]) ⊙ g|` — T0 sets `movement = D_margin / |(E[answer_k] − E[competitor_k]) ⊙ g|` at the battle position; keeping the answer token's `dot_scale` would mis-size every battle row, and the error grows as the two embeddings get similar. The unit test checks the MAGNITUDE, not just the direction.
- **Degeneracy is near-zero, not exactly zero (verdict amendment 2):** when the competitor's embedding is close-but-not-equal (similar subwords), `|(E_a − E_c) ⊙ g| → 0` and the movement explodes through any `1e-9` guard. The fallback fires on a RELATIVE threshold — `|Δ⊙g| < τ·|E[answer_k]⊙g|` with τ pre-registered (T0 pins the constant; default 0.1) → the absolute target verbatim. The movement itself also carries its own pre-registered clamp, independent of the D cap. When the base model already answers correctly (the exact-equality face), the same fallback fires — the margin lever only bites on mis-ranked facts, and on a well-known fact it is a graceful no-op. Pin BOTH shapes in tests.
- **Margin sizing + the cap (verdict amendment 3 — the cap cannot sit below the margin it must close):** `D_margin = clamp(lp(competitor_k) − lp(answer_k), 0, margin_cap) + floor`, read at the CURRENT overlay state each round (an exact logit gap — the softmax normalizer cancels, so the comparison is sound). The standing `shortfall_cap_nats` (5.0) is BELOW the anchor's plausible margin (lp −4..−10 → gap ≥ 10 nats), so a hard-wired 5-cap would make one round ASKABLE for less than the flip requires and any depth-0 read would reflect the cap, not the objective. Fix: `--phase-a-only` records the measured battle-position margin per training ask; T1's pre-registration (before the armed run) sets `margin_cap_nats ≥ measured_margin + floor` as part of the cell; the value rides the manifest echo.
- **Flag + scope:** `FactWriteConfig::margin_target: bool` default `false` — flag-off is byte-identical Recipe-1/2 by construction (the code path is an `if`). Harness flag `--margin-target`; optional authored override rides the `--facts` doc (`competing_first_token` per ask, first token read) for probe-grade control; absent field = auto-capture. Everything under the existing `closed_form_write` feature; no serving path; the base artifact never moves.
- **Protection unchanged:** ask-position keys, look-alike contrast rows, control rows, earlier-fact rows — all weights and shapes exactly today. The differential direction is applied at the fact's own battle-position keys only; G1b look-alikes ("The capital of Italy is" → Rome) and controls stay the standing gates. The direction does push AWAY from the competitor token's embedding — that is the point — and the look-alike gate is what proves it does not leak.
